# Kalnmuiža — Heritage Editorial demo

Vienas lapas, autonomi atverams HTML/CSS demo pēc WEBAGENCY_OS MASTER. Šis nav Kalnmuižas oficiālais resurss.

## Atvērt
Atveriet `index.html` jebkurā pārlūkā. Nav npm, datubāzes, servera, izsekošanas vai API atkarību. Telefonam ir īsta `tel:` saite. Rezervācijas forma netiek imitēta.

## Sadaļas
Hero → Par Kalnmuižu → Svinības un atpūta → Galerija → Atrašanās vieta → Kontakti.

## Attēli
Foto netika publicēti, jo izmantošanas atļauja un pēcugunsgrēka aktualitāte nav verificētas. Trīs galerijas vietturi un Hero foto laukums ir skaidri marķēti. Kad saimnieks apstiprinās aktuālus īstos kadrus, aizvietojiet vietturus ar pieejamiem attēliem, optimizētiem WebP/AVIF.

## Drošība un stāvoklis
Neoficiāls `noindex,nofollow` demo. Nekādi personas dati netiek vākti. Skatiet `PROJECT_STATE.md` par informācijas precizējumiem un QA.

## Ierobežojums
Kestrel `main` un citi projekti nav skarti; tikai šī mape izolētā darba zarā.
